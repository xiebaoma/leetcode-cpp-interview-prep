6 模18加法群中元素的阶

6.1 概述
实现功能：
本程序实现了计算模18加法群（Z₁₈）中元素的阶。程序能够：
- 读取一个整数a
- 将a取模18，确保在[0, 17]范围内
- 计算元素a在模18加法群中的阶
- 输出阶的值

**群论背景**：在模n加法群中，元素a的阶等于n / gcd(n, a)，表示需要多少次加法运算（a + a + ... + a）才能得到单位元0。

6.2 步骤流程图
```
┌─────────────────┐
│  输入整数a      │
└────────┬────────┘
         ↓
┌─────────────────────┐
│  将a取模18          │
│  ┌────────────────┐ │
│  │ a = (a%18+18)%18│ │
│  │ 确保在[0,17]   │ │
│  └────────────────┘ │
└────────┬────────────┘
         ↓
    ┌────┴────┐
    ↓         ↓
┌─────────┐ ┌─────────────┐
│ a == 0? │ │ a != 0      │
└────┬────┘ └──────┬──────┘
     │             │
     ↓是          ↓否
┌─────────┐ ┌─────────────┐
│ 输出1   │ │ 计算gcd(18,a)│
│ (0的阶) │ └──────┬──────┘
└─────────┘        │
                   ↓
            ┌─────────────┐
            │ 阶 = 18/gcd │
            └──────┬──────┘
                   │
                   ↓
            ┌─────────────┐
            │  输出阶的值  │
            └─────────────┘
```

6.3 程序实现

**函数1: gcd(int a, int b)**
功能：使用欧几里得算法（辗转相除法）计算两个整数的最大公约数。递归实现：当b为0时返回a，否则递归计算gcd(b, a % b)。这是计算元素阶的关键函数。

**函数2: 输入处理和取模运算（main函数中的输入部分）**
功能：读取输入的整数a，然后将其取模18。使用公式 `((a % 18) + 18) % 18` 确保结果在[0, 17]范围内，正确处理负数情况。

**函数3: 特殊情况处理（a == 0）**
功能：处理元素0的特殊情况。在模18加法群中，0是单位元，0的阶为1（因为0 + 0 = 0，只需1次运算就得到单位元本身）。

**函数4: 计算元素阶（main函数中的核心计算）**
功能：对于非零元素a，计算其在模18加法群中的阶。使用公式：阶 = 18 / gcd(18, a)。这个公式基于群论理论：在模n加法群中，元素a的阶等于n除以a与n的最大公约数。例如，如果gcd(18, a) = 3，则阶 = 18/3 = 6，表示需要6次a的加法才能得到0。
